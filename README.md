Todo App
A modern and advanced Todo App built with HTML, CSS, and JavaScript.
This project includes CRUD operations, filtering, search, dark/light mode, and localStorage support.

Features
- Add new task
- Delete tasks
- Mark tasks as completed
- Edit support (structure ready for upgrade)
- Search tasks
- Filter (All / Active / Completed)
- Dark / Light mode
- LocalStorage (data saved in browser)


Built With
- HTML5
- CSS3
- JavaScript
